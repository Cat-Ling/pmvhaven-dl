### PMVHaven-DL

This is a quickly cooked up experimental project I made for personal use. I only built it up to the point that it fits my use case.
You'll find things like playlist downloads missing because I didn't want to add a separate flag for --no-playlist when wanting to download a single video from a playlist.


The codebase is small so you can throw it at your AI and can get it to give you what you want.

Linux binary is in the releases. It should work on other oses though you'd have to build it yourself.
